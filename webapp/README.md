# 무한매수법 V4.0 계산기 (TQQQ) — Next.js

라오어 무한매수법(TQQQ 40/20분할 전략) 주문표 계산기. 기존 단일 HTML 파일을
Next.js(App Router) + TypeScript로 재구현한 버전입니다.

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 접속.

## 배포 (Vercel)

이 `webapp/` 폴더를 프로젝트 루트로 지정해서 Vercel에 연결하면 됩니다
(레포 루트가 아니라 `webapp/`가 Root Directory).

```bash
npm run build
```

## 구조

- `src/lib/calc.ts` — 별% / 일반모드 / 리버스모드 주문표 계산, 체결 반영 로직 (순수 함수)
- `src/lib/storage.ts` — localStorage 저장/불러오기
- `src/components/` — UI 컴포넌트
- `src/app/page.tsx` — 메인 페이지, 상태 관리

## 기존 HTML 버전 대비 변경점

1. **리버스모드 매도수량 자동 재계산**: 매도수량은 항상 "직전 보유수량 ÷ 10(20분할)/20(40분할)"으로
   현재 공통설정의 보유수량을 기준으로 매번 다시 계산됩니다. 체결 반영 시에도 리버스모드 전용
   T값 공식(매도 시 ×0.95/×0.9, 매수 시 직전T+(분할수-직전T)×0.25)을 선택해 적용할 수 있습니다.
2. **동시 다중가격 매도 체결 입력**: 체결 입력 카드에서 매도 체결을 여러 건(수량+가격) 추가할 수
   있습니다. 쿼터매도와 15%목표 매도가 같은 날 서로 다른 가격에 체결되는 사이클 종료 시나리오를
   가중평균 계산 없이 그대로 입력 가능합니다. 그날 매도 후 보유수량이 0이 되면 사이클 종료로 보고
   T값을 자동으로 0으로 리셋합니다.
3. 데이터는 브라우저 `localStorage`(`muhan_state_v2`, `muhan_profit_v2`)에 저장됩니다. 기기 간
   동기화가 필요하면 추후 Supabase 등 백엔드 연동을 추가할 수 있습니다.

## 데이터 검증

인수인계 문서(2사이클 리버스모드 시나리오: T=40.11 진입 → 다음날 종료조건 즉시 충족 → T=38.10로
일반모드 복귀)로 계산 결과를 검증했습니다.
