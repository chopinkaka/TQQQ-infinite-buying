# TQQQ 무한매수법 계산기

TQQQ 매매를 위한 개인용 주문표 계산기입니다. 백엔드 없는 단일 정적 페이지(`index.html`)로 동작하며, 입력 데이터는 브라우저 `localStorage`에만 저장됩니다.

## 사용 방법

`index.html`을 브라우저로 열거나, GitHub Pages로 배포된 주소에 접속하면 됩니다.

## 주요 기능

- 전일 체결 입력 → 자동 상태 업데이트 (미리보기 후 반영)
- 원금/분할수/평단/보유수량/잔금 등 공통 설정 관리
- 진행회차(T값) 추적 및 시각화
- 일반모드 / 리버스모드 매매 주문표 계산
- 사이클별 수익률 기록

## 데이터

모든 데이터는 브라우저 `localStorage`에 저장되며, 설정 화면에서 백업(내보내기/가져오기) 및 초기화가 가능합니다.
